# TradeScout Default Profile

## Product decision

The AutoBott operator console is the reference template for the default TradeScout profile, adapted to the
TradeScout visual system and voice.

The profile is the canonical customer-facing identity. It should feel operational, connected, and specific to the
customer rather than like a generic site theme. The positioning is **your business, connected**.

## Included for free

- the default TradeScout profile in the standard house style
- customer-controlled profile content, settings, and supported visual customization
- the documented tools needed to make those supported changes without paying TradeScout

## Paid services

- done-for-you visual and content customization
- bespoke workflows or profile components
- third-party data, account, catalog, scheduling, or operational integrations
- migration, implementation, and ongoing managed work

Straightforward work may use a standard service price. Complex integrations and managed implementations require a
custom quote.

## Product boundaries

- Free self-customization must remain a real option; paid service is for execution, expertise, and integration depth.
- Do not use fake ratings, fabricated claims, or generic marketplace language.
- Trading-profile display preferences must not silently alter the automated execution policy. In the AutoBott
  reference profile, the configurable Manual Mirror contract-cost cap applies only to that dashboard panel.
- Safety, authentication, and audit controls are part of the template and are not cosmetic claims.
